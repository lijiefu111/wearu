# 百搭 · BaiDa

> AI 私人穿搭伙伴（移动端原型）——围绕你**真实拥有的衣橱**，帮你从「衣柜里有」走到「今天穿了、感觉不错」。

**在线体验(手机打开更佳)**：https://lijiefu111.github.io/Baida/

---

## 这是什么

大多数人不缺衣服，缺的是每天出门前那 5 分钟的判断力：不知道怎么搭、买了不会穿、还在重复消费。

**百搭** 以「你真实拥有的 24 件单品」为起点，跑通一条能自我增强的闭环：

```
衣橱 → 选场合/指定单品 → AI 出 3 套方案 → 数字人试穿
     → 穿这套 → 写入日记(单品穿着 +1) → 近 30 天个人画像
     → 衣橱诊断(连接度/缺口) → 智能选购 → 穿搭社区找同款
```

## 四个核心模块

| 模块 | 做什么 |
| --- | --- |
| **衣橱** | 24 件真实单品分 6 类管理；拍照 / 上传 / 导购物链接入库；可删除；实时统计各类目件数 |
| **穿搭** | 先选场合(或自由填写) → 可从衣橱指定单品 → 生成 3 套差异化方案(横滑) → 数字人 / 本人照片试穿 → 「穿这套」写入日记 |
| **日记** | 年/月/日可选日历(有记录带圆点)；当天感受可多选标签 + 自由填写；支持拍实穿照；自动生成近 30 天个人画像(最常穿单品、高频场景、偏好风格) |
| **购物** | 衣橱诊断(连接度 + 4 个缺口) → 逐一对应的推荐单品(商品图 + 数字人上身 + 试穿 + 找同款跳电商)；「买了能这么穿」搭配示例；穿搭社区 OOTD |

## 关键设计取舍

- **从「衣橱」进，而不是种草流**：你拥有什么，是所有 AI 推荐的前提；打开就种草，产品立场就站到了用户对面。
- **一次只给 3 套、可横滑**：减少决策成本是核心价值，给方向而不是给负担。
- **商业化克制**：推荐必须由「衣橱诊断出的真实缺口」推导（例如「包袋 0 件 → 推荐斜挎包」），预算由用户给定，不做无脑种草。
- **虚拟试穿明确标注「仅供参考、非真实合身」**：体验放大器，不做过度承诺。

## 指标口径

- **北极星**：用户采纳推荐并**真实穿着**的次数（不是 DAU，也不是 GMV）。
- 护栏指标：推荐关闭率、试穿预期落差反馈、种草感投诉。

## 技术说明

- **零依赖静态站**：`index.html` + `src/app.js` + `src/styles.css`，原生 JS 状态驱动渲染，无构建步骤。
- **本地持久化**：衣橱 / 日记 / 个人档案 / 头像存 `localStorage`，数据不出设备。
- **自动天气**：`navigator.geolocation` → IP 定位兜底 → Open-Meteo，逆地理编码取城市名。
- **当前为原型**：识别、搭配、试穿为受控演示。走向真实产品还需：账号系统与云端同步、多模态衣物识别 + 抠图分割、把「衣橱 + 天气 + 场合 + 画像 + 反馈」作为结构化上下文交给大模型推理、虚拟试穿模型、以图搜图 + 电商对接。
